# Code of Conduct

This is a small project with a small (possibly one-person) community, so the rules are
short:

**Be decent.** Assume good faith, keep criticism about the code, and skip the personal
stuff. Harassment, insults, and discrimination aren't welcome here.

If someone's behaviour is a problem, report it through GitHub's **Security → "Report a
vulnerability"** flow (the only private channel this repo has) or by opening an issue.
As the maintainer I'll deal with it as best I can — which may mean editing or deleting
comments, or blocking accounts.

This is a condensed, plain-language stand-in for the
[Contributor Covenant](https://www.contributor-covenant.org/). Where this is silent,
that's the spirit to follow.
